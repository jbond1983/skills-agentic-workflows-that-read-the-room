## Recent updates (October 2026)

### Collaboration
- **Stacked pull requests are generally available** (Oct 6). Break big changes into small, reviewable PRs that build on each other. Source: [GitHub Changelog](https://github.blog/changelog/).
- **Saved whitespace preferences and improved split view in pull requests** (Oct 22). Review diffs your way, every time. Source: [GitHub Changelog](https://github.blog/changelog/).
- **Triage role and above can archive pull requests** (Oct 8). Source: [GitHub Changelog](https://github.blog/changelog/).

### GitHub Copilot
- **Local sandboxing for GitHub Copilot is generally available** (Oct 7), so agent actions can run with tighter limits. Source: [GitHub Changelog](https://github.blog/changelog/).
- **Claude Haiku 5.5 is available in Copilot** (Oct 7). Source: [GitHub Changelog](https://github.blog/changelog/).
- **Copilot CLI can discover local models** (Oct 7). Source: [GitHub Changelog](https://github.blog/changelog/).
- **Heads up:** some Copilot models were deprecated on Oct 19, with more planned for mid-November. Check your model picker. Source: [GitHub Changelog](https://github.blog/changelog/).

### GitHub Actions
- **Workflow lockfiles are in public preview** (Oct 14), helping make workflow runs more reproducible. Source: [GitHub Changelog](https://github.blog/changelog/).
- **Xcode 27 runner image is generally available** (Oct 15). The macOS 14 runner image was retired on Oct 1. Source: [GitHub Changelog](https://github.blog/changelog/).

### Security
- **Agentic autofix for code scanning alerts and AI Scan for pull requests are generally available** (Oct 15). Source: [GitHub Changelog](https://github.blog/changelog/).
- **Secret scanning now blocks Anthropic keys by default** (Oct 13). Source: [GitHub Changelog](https://github.blog/changelog/).

## Learn more: agentic workflow examples

The [Awesome Copilot workflows collection](https://github.com/github/awesome-copilot/tree/main/workflows) has ready-to-adapt examples, including a daily issues report, OSPO org health and stale-repo reports, and a weekly comment sync. They are a good starting point for GitHub Actions automation with Copilot.
